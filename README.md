# Spoon It

Прототип кооперативной игры про абсурдную заботу: напоить зверёнка из адской щели всем Мировым океаном с ложки.
Играется в браузере на компьютере, лучше на весь экран.

- `prototype-2d/`: основной прототип. На острове камера сверху под углом, в море она за кормой корабля.
- `prototype/`: первый прототип, 3D от первого лица.

## Управление

| Клавиши | Что делают |
|---|---|
| WASD | Идти. На корабле W и S ход, A и D руль |
| Shift | Бежать |
| Пробел | Кувырок |
| ЛКМ | Использовать предмет. В пещере удар, удержание сильный удар |
| ПКМ | В пещере бросить карты. В море осмотреться |
| E | Действие: разговор, сундук, верстак, корабль, машина, мост, пещера, рыбалка |
| Колесо, + и − | Отдалить и приблизить камеру |
| T / I / M | Навыки / инвентарь / карта |
| L / C | Фонарь включить и выключить / зарядить |
| V | Надеть или снять ролики |
| F / G / H / B | Поесть / тайник / святая вода / костёр |
| 1–4 | Слоты панели снизу |
| Q | Подобрать лут с земли |
| Esc | Закрыть окно, без окон открыть меню: продолжить или начать заново |

Игра сохраняется сама в браузере каждые 15 секунд, кроме пещеры. На стартовом экране можно продолжить или начать новую игру.

Для проверки: N ночь, K почти полная шкала, P высеребро и опыт, J еда и дрова, O карта сокровищ, U в пещеру, Q землетрясение.

Локально: `python3 -m http.server --directory prototype-2d 8124`, затем открыть http://localhost:8124
